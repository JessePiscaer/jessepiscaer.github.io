# jessepiscaer.com

Personal website for Jesse Piscaer — technology leader, mentor, and builder.

**Live:** [jessepiscaer.com](https://www.jessepiscaer.com)

## Stack

- Static HTML + CSS (no frameworks, no build step)
- Hosted on GitHub Pages with custom domain
- [Inter](https://fonts.google.com/specimen/Inter) + [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) via Google Fonts
- [Font Awesome 6](https://fontawesome.com/) for icons

## Local Development

Open `index.html` in a browser. That's it.
